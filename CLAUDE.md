# Инструкции для Claude

Главные правила проекта в AGENTS.md, они действуют всегда:

@AGENTS.md

## С чего начинать каждую сессию

1. Открой `знания/онбординг.md`.
   - Если в нём нет строки `Статус: завершён`, начни онбординг по `ОНБОРДИНГ.md`. Пока он не закончен, другими задачами не занимайся.
   - Если онбординг пройден, перечитай `знания/предпочтения.md` и `знания/приоритеты.md`. Поздоровайся по имени, одной строкой напомни три приоритета и спроси, чем заняться.
2. Перед любой задачей перечитай раздел «Правки» в `знания/предпочтения.md`: там поправки руководителя, их нельзя повторять.

## Навыки проекта

Лежат в `.claude/skills/`. Используй навык, когда задача совпадает с его описанием.

| Навык | Когда |
|---|---|
| `utrennyaya-svodka` | утренняя сводка: продажи, вагоны, поручения, производство, день руководителя |
| `protokol-planerki` | разобрать запись или заметки планёрки в протокол и задачи |
| `kontrol-vagonov` | сверить таблицу отгрузок с регламентом посадки |
| `grafik-oplat` | график оплат заводам и сколько денег нужно в обороте |
| `sravnenie-cen` | наши цены против конкурентов и себестоимости, сигнал на акцию |
| `proverka-zakupa` | проверить предложения поставщиков ТМЦ по ценам рынка |
| `plan-fakt-prodazh` | план-факт продаж по филиалам и клиенты, которые перестали покупать |
| `plan-fakt-proizvodstva` | план-факт и брак производства по выгрузке 1С |
| `obezlichivanie` | убрать персональные данные из таблицы перед работой с ней |

## Сверка перед показом

Любую сводку, план-факт, сравнение цен или расчёт перед показом руководителю отдай агенту `sverka` (`.claude/agents/sverka.md`). Он проверяет каждую цифру по исходному файлу. Расхождения исправь до показа.

## Голос

Руководитель часто отвечает голосом, в тексте бывают ошибки распознавания. Понимай по смыслу. Переспрашивай, только если от слова зависит решение: имя, сумма, дата, филиал.
