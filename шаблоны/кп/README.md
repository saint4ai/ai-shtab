# Шаблоны коммерческих предложений

Два шаблона в стиле «жидкое стекло»: холодная сталь, графит и один акцентный цвет, поверх них стеклянные панели. Фирменный знак шаблонов: сечения металлопроката (арматура, круг, лист, трубы, уголок, швеллер, двутавр, проволока, сетка). Результат: PDF формата A4, книжный.

Все названия, имена и цены в примерах выдуманы. Ставка НДС в примерах условная: впишите действующую.

## Как получить КП (для руководителя)

Скажите агенту: «Сделай КП для ТОО ... на такие позиции ...». Агент спросит недостающее, возьмёт цены из вашего прайса, соберёт файл и покажет PDF. Клиенту файл уйдёт только после вашего «да». Один раз агент спросит логотип и фирменные цвета и запомнит их.

| Шаблон | Для чего | Листов |
|---|---|---|
| `postavka` | КП на поставку: шапка, таблица позиций, итог, условия, менеджер | 1-2, длинная таблица переносится дальше |
| `prezentaciya` | КП-презентация для крупного клиента или тендера: обложка, о компании, ассортимент, цены, логистика, условия, контакты | 4-6, разделы без данных не выводятся |

## Как собрать (для агента)

```bash
python3 tools/kp.py презентации/данные.json                 # HTML в презентации/КП_<клиент>_<дата>.html
python3 tools/kp.py презентации/данные.json --vyhod путь.html
python3 tools/sobrat_pdf.py путь.html --knizhnaya            # PDF рядом с HTML
```

Скрипт сам считает суммы и НДС (Decimal, округление до тенге), раскладывает таблицу по листам с повтором шапки, экранирует текст и встраивает шрифты, иконки и логотип: HTML открывается где угодно без интернета. Если файл с таким именем уже есть, к имени добавится `_v2`. Явный `--vyhod` перезаписывает файл. Суммы агент не считает: он берёт их из ответа скрипта и сверяет с источником (агент `sverka`).

Ошибки данных скрипт показывает списком: что не так и что поправить. Незнакомое поле (возможно, опечатка) он не пропускает молча, а пишет «Внимание».

## Формат данных (JSON)

Пример КП на поставку, файл `primer_postavka.json`:

```json
{
  "template": "postavka",
  "brand": {"accent": "#F08A24", "accent2": "#4F6D8A", "logo": "знания/бренд/logo.png"},
  "company": {"name": "ТОО «Дала-Сталь Групп»", "tagline": "Металлопрокат оптом и в розницу",
              "address": "г. Алматы, ул. Прокатная, 7, склад 4", "phone": "+7 727 000 00 01",
              "email": "sales@dala-stal.example", "site": "dala-stal.example"},
  "number": "КП-0147",
  "date": "2026-11-21",
  "client": {"name": "ТОО «Бозтау-Монолит»", "contact": "Серик Абдрахманов, начальник отдела снабжения"},
  "intro": "Предлагаем металлопрокат со склада в Алматы под ваш объект на северной окраине города.",
  "items": [
    {"name": "Арматура рифлёная А500С", "size": "Ø12 мм, 11,7 м", "unit": "т", "qty": 20, "price_kg": 342},
    {"name": "Лист горячекатаный", "size": "4×1500×6000, Ст3сп", "unit": "лист", "qty": 40, "price": 118500}
  ],
  "vat": {"rate": 16, "included": false, "note": "Цены указаны без НДС."},
  "terms": [{"label": "Оплата", "text": "Предоплата 50%, остаток в день отгрузки."}],
  "manager": {"name": "Ермек Нурланов", "position": "Менеджер по работе с корпоративными клиентами",
              "phone": "+7 700 000 00 02", "email": "e.nurlanov@dala-stal.example"}
}
```

Пример КП-презентации, файл `primer_prezentaciya.json`: те же поля плюс разделы, которых нет в `postavka` (показан по одной записи, полный файл рядом):

```json
{
  "template": "prezentaciya",
  "subject": "Поставка металлопроката на строительство логистического центра в Астане",
  "about": {"text": "Торгуем металлопрокатом и производим профлист и сетку.",
            "facts": [{"value": "12", "label": "филиалов по Казахстану"}]},
  "assortment": [{"title": "Арматура", "icon": "armatura", "items": ["А500С, Ø6–40 мм", "А240 гладкая"]}],
  "logistics": {"steps": [{"title": "Завод", "text": "Отгрузка по вашей заявке.", "term": "1–2 дня"}],
                "note": "Срочный заказ из наличия отгружаем в течение суток."},
  "why": [{"title": "Цена фиксируется", "text": "На весь срок поставки по договору."}]
}
```

Третий пример, `primer_dlinnyy_brend.json`: 40 позиций с длинными наименованиями, бренд с другим акцентом и PNG-логотипом (`logo_primer.png`), текст с казахскими буквами. Он нужен как проверка: шаблон должен держать чужой цвет и длинную таблицу.

### Поля

| Поле | Что это | Обязательно |
|---|---|---|
| `template` | `postavka` или `prezentaciya` | да |
| `company.name` | название вашей компании (до 80 знаков) | да |
| `company.tagline`, `address`, `phone`, `email`, `site` | подпись и контакты компании | нет |
| `company.branches` | список городов, вместе до 260 знаков (только в презентации) | нет |
| `client.name`, `client.contact` | кому адресовано; контактное лицо | имя да |
| `number`, `date` | номер КП; дата как `2026-11-21` или `21.11.2026` (нет даты: сегодня) | нет |
| `intro` | одна строка вступления, до 190 знаков (`postavka`) | нет |
| `subject` | тема на обложке, до 140 знаков (`prezentaciya`) | нет |
| `items[]` | позиции: `name`, `size` (размер или марка), `unit` (до 5 знаков: т, м, лист, бухта, штука), `qty` и `price` | хотя бы одна |
| `items[].price_kg` | вместо `price` (оба сразу нельзя), цена за кг при единице `т`: скрипт умножит на 1000 | нет |
| `vat` | `rate` (ставка в %), `included` (`true`: цены уже с НДС, `false`: НДС добавляется; обязательно при ставке, только без кавычек), `note` (фраза под таблицей) | нет |
| `terms[]` | условия: `label` и `text`, до 8 | нет |
| `manager` | `name`, `position`, `phone`, `email` | нет |
| `brand` | `accent`, `accent2` (цвета вида `#F08A24`), `logo` (путь к PNG, SVG, JPG или WebP до 2 МБ) | нет |
| `about`, `assortment`, `logistics`, `why` | разделы презентации, без данных не выводятся | нет |

Правила цифр:

- Цена и количество больше нуля, иначе скрипт остановится и скажет, какая позиция не подошла. Позицию без цены не выдумывают: уточните цену.
- Цена задаётся за единицу из `unit`. Количество показывается до трёх знаков, цена до двух, сумма позиции округляется до тенге. Итог равен сумме строк, как они напечатаны. Числа должны помещаться в колонку одной строкой: количество примерно до 9 999,999, цена до 9 999 999, сумма позиции до 9 999 999 999. Не помещается: скрипт назовёт позицию.
- Ставка НДС нигде не зашита. `included: true`: цены уже с НДС, в итогах строка «В том числе НДС». `included: false`: НДС добавляется к сумме. Нет `rate`: считать нечего, остаётся только фраза из `note`. Скрипт не сверяет фразу из `note` со значением `included`: пусть они говорят одно и то же.
- Валюта всегда тенге (₸).

Лимиты длины защищают лист от обрезанного текста: при превышении скрипт назовёт поле и допустимое число знаков. Групп ассортимента до 8 (при больше шести групп в списке группы до 3 строк), шагов логистики до 6, пунктов «почему мы» до 4, фактов-цифр до 4.

Иконки сечений: `armatura`, `krug`, `list`, `truba`, `profil_truba`, `ugolok`, `shveller`, `dvutavr`, `provoloka`, `setka`. Значки логистики: `zavod`, `stanciya`, `sklad`, `obekt`, `gruz`. Если иконка не указана, скрипт выбирает её по слову в названии (арматура, труба, швеллер, завод, склад и так далее).

## Бренд

Без `brand` шаблон выглядит законченно: графит и сталь с янтарным акцентом, вместо логотипа знак из букв названия. С `brand` акцент и свечение берутся из ваших цветов. Скрипт сам осветляет слишком тёмный цвет для текста и приглушает слишком яркий второй цвет, чтобы читалось. Логотип кладётся на светлую плашку: тёмный или цветной логотип подойдёт, белый нет.

## Что внутри папки

| Файл или папка | Что это |
|---|---|
| `стили.css` | весь вид: лист, стекло, таблица, разделы |
| `общее.html`, `postavka.html`, `prezentaciya.html` | блоки вёрстки, которые собирает `tools/kp.py` |
| `иконки/` | сечения проката и значки логистики (SVG) |
| `фон/` | фоновый декор листов, четыре варианта |
| `шрифты/` | Tektur (заголовки и крупные цифры) и Onest (текст) с лицензией SIL OFL 1.1; есть кириллица, казахские буквы ә ғ қ ң ө ұ ү һ і и знак ₸ |

## Если правите вид

- Chromium при печати в PDF отбрасывает `backdrop-filter`, поэтому стекло сделано иначе: у каждой панели внутри лежит размытая копия фона листа. Правило в шапке `стили.css`: у предков панели внутри листа нет `position`, `transform`, `filter`, `contain`, а стекло внутри стекла не вкладывается. Нарушите его, и копия фона съедет.
- Высоты строк таблицы скрипт оценивает по тексту с запасом (константы `G` в `tools/kp.py`). Поменяли шрифт, размер или отступы таблицы: пересоберите `primer_dlinnyy_brend.json` и посмотрите, что нижний край листов остаётся свободным.
- Проверка PDF: `pdftoppm -r 110 -png файл.pdf страница`, затем посмотреть каждую страницу глазами.
- Вид проверен в Chromium (через `sobrat_pdf.py`). В Safari и в просмотрщике WhatsApp HTML не проверялся, надёжный путь это PDF.
