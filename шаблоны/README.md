# Шаблоны таблиц

Эталонные колонки. Таблицы филиалов бывают разными: агент сводит их к этим колонкам, показывает сопоставление и только потом считает.

| Файл | Для чего |
|---|---|
| `вагоны.csv` | контроль отгрузок и посадки, считает `tools/vagony.py` |
| `план_факт_продаж.csv` | план-факт по филиалам и группам товаров |
| `оплаты.csv` | график оплат заводам: валюта, курс Нацбанка, кредит и отсрочки отдельно |
| `закуп.csv` | проверка предложений поставщиков ТМЦ |
| `цены.csv` | сравнение цен с конкурентами и себестоимостью: цена за кг и за единицу (метр, лист, бухта), считает `tools/ceny.py` |
| `задачи.csv` | контроль поручений из Битрикс24 и протоколов |
| `предложения_заводов.csv` | закуп у заводов на месяц |
| `продажи_конкурентов.csv` | кто у конкурентов что покупает |
