# Источники данных: как получить данные

Начинаем с выгрузок: это безопасно и работает сразу. Прямые подключения настраиваем на созвонах обучения. Все файлы кладём во `входящие/`.

## Битрикс24

- **Задачи:** Задачи → вид «Список» → шестерёнка справа вверху → «Экспорт списка в Excel» → выбрать поля → «Выполнить» → «Скачать файл экспорта».
- **Сделки и контакты:** CRM → нужный раздел → вид «Список» → фильтр → шестерёнка «Настройки» → «Excel» или «CSV» → «Выполнить» → скачать. Экспорт контактов есть не на всех тарифах.
- **Прямое подключение (вебхук):** режима «только чтение» в Битрикс24 нет, вебхук может всё, что может сотрудник, который его создал. Поэтому подключаем только от отдельного сотрудника с правами на просмотр. Адрес вебхука хранится в `.private/`, в чат и в git не попадает. Настраиваем на созвоне.

## 1С

- **Отчёт:** сформировать отчёт → «Файл → Сохранить как» → тип «Лист Excel (*.xlsx)».
- **Список** (номенклатура, контрагенты, документы): «Ещё → Настройка списка» (колонки, отбор) → «Ещё → Вывести список» → сохранить как .xlsx.
- **Прямое подключение на чтение** (OData, названия контрагентов приходят метками): урок 2 «Навыки и MCP», ставим вместе с Александром. Доступ OData включает администратор 1С.

## Google Таблицы

- **Просто:** Файл → Скачать → Microsoft Excel (.xlsx).
- **В Claude Desktop:** Настройки → Коннекторы → Google Drive. Claude читает таблицы до ~10 МБ.
- Таблицы с доступом «всем по ссылке» не делаем: это публикация данных компании.

## Записи планёрок и созвонов

- **Zoom (тариф Pro и выше):** включить облачную запись и «Create audio transcript». Готовую расшифровку кладём во `входящие/`.
- **Битрикс24:** запись звонков есть. Расшифровка встреч зависит от тарифа, проверим на вашем портале.
- **Диктофон или любая запись:** расшифровываем на этом Mac. Нужен Mac на процессоре Apple (M1 и новее). Пароль администратора не нужен:

```bash
cd ~/ai-shtab
python3 -m venv .venv
.venv/bin/pip install mlx-whisper imageio-ffmpeg
mkdir -p .venv/ffbin
ln -sf "$(.venv/bin/python -c 'import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())')" .venv/ffbin/ffmpeg
PATH="$PWD/.venv/ffbin:$PATH" .venv/bin/mlx_whisper "входящие/запись.m4a" \
  --model mlx-community/whisper-large-v3-turbo --language ru \
  --condition-on-previous-text False --word-timestamps True \
  --hallucination-silence-threshold 2 --output-dir входящие
```

Последние три флага обязательны: без них на длинной записи Whisper начинает повторять одну фразу. Модель около 1,6 ГБ скачивается при первом запуске. Ставить только после «да» руководителя.

## Цены рынка

- **Satu.kz** отдаёт цены обычным запросом.
- **Kaspi.kz** показывает цены только в браузере: открывай встроенным браузером Claude или попроси у руководителя ссылку или скриншот.
- **OLX.kz** запросы программ блокирует.
