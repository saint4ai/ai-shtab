# Словарь компании

| Слово | Что значит |
|---|---|
| Посадить товар | оприходовать поступление в 1С |
| Прокат, прокатка | выпуск металлопроката; «отчёт прокатки» показывает, сколько выпустили за день |
| График проката | план выпуска завода-поставщика: по нему видно, когда пойдёт товар |
| Вагон | полувагон с металлом от завода, номер из 8 цифр |
| ТМЦ | товарно-материальные ценности для офисов и заводов: шины, стропы, запчасти, канцелярия |
| Ø12, А500С | диаметр и класс арматуры |
| План-факт | сравнение плана с фактом за период |
| РОП | руководитель отдела продаж |
| Себестоимость | стоимость единицы товара по данным 1С |
| Повторная продажа | сделка с клиентом, который уже покупал |

Новые слова руководителя добавляй сюда.
