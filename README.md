# AI-штаб руководителя

Рабочий проект для Claude: агент помогает руководителю торговой и производственной компании держать руку на пульсе. Утренняя сводка, поручения после планёрок, вагоны и посадка, цены и конкуренты, закуп, продажи по филиалам.

Проект собран для личного обучения у Александра ([@saint4ai](https://instagram.com/saint4ai)).

## Как начать

1. Установите Claude Desktop на Mac и войдите в свой аккаунт.
2. Откройте вкладку **Code** и напишите:
   > Разверни проект по ссылке https://github.com/saint4ai/ai-shtab и познакомься со мной
3. Агент сам скачает проект, прочитает инструкции и задаст вам вопросы о компании и задачах. Отвечать можно голосом: кнопка микрофона в поле ввода. Если Claude спросит разрешение записать файл в папку проекта, разрешите.
4. Дальше открывайте проект так: вкладка **Code**, выбрать папку `ai-shtab`.

Данные вашей компании остаются на вашем компьютере. Агент ничего не покупает, не вводит пароли и пишет людям только после вашего «да».

## Для Claude и других AI-агентов

Пользователь дал тебе ссылку на этот репозиторий. Порядок действий:

1. Склонируй проект в домашнюю папку пользователя:
   `git clone https://github.com/saint4ai/ai-shtab ~/ai-shtab`
   Если git не установлен или просит установить инструменты разработчика, скачай архив и распакуй:
   `curl -L -o /tmp/ai-shtab.zip https://github.com/saint4ai/ai-shtab/archive/refs/heads/main.zip && unzip -q /tmp/ai-shtab.zip -d /tmp && mv /tmp/ai-shtab-main ~/ai-shtab`
2. Прочитай `~/ai-shtab/CLAUDE.md`, `~/ai-shtab/AGENTS.md` и `~/ai-shtab/ОНБОРДИНГ.md`.
3. Сразу начни онбординг по `ОНБОРДИНГ.md`. Пока он не закончен, другими задачами не занимайся.
4. Все ответы пользователя записывай в файлы проекта в `~/ai-shtab`, как сказано в `ОНБОРДИНГ.md`.
