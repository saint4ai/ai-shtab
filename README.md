# AI-штаб руководителя

Рабочий проект для Claude: агент помогает руководителю торговой и производственной компании держать руку на пульсе. Утренняя сводка, поручения после планёрок, вагоны и посадка, цены и конкуренты, закуп, продажи по филиалам.

Проект собран для личного обучения у Александра ([@saint4ai](https://instagram.com/saint4ai)).

## Как начать

1. Установите Claude для Mac ([claude.com/download](https://claude.com/download)) и войдите в свой аккаунт. Нужна платная подписка, на бесплатной вкладка **Code** не работает.
2. Скачайте рабочую папку архивом по ссылке из урока 1 и откройте архив двойным щелчком. Появится папка `ai-shtab`. Если скачиваете здесь, на GitHub (кнопка **Code → Download ZIP**), папка будет называться `ai-shtab-main`: переименуйте её в `ai-shtab`.
3. В Finder нажмите ⇧⌘H, откроется папка с вашим именем. Перетащите `ai-shtab` туда. В «Загрузках», «Документах» и на «Рабочем столе» папку не оставляйте: оттуда macOS не пустит автозапуск WhatsApp.
4. В Claude откройте вкладку **Code**, выберите папку `ai-shtab` и напишите «Привет». Агент прочитает инструкции и задаст вам вопросы о компании и задачах. Отвечать можно голосом: кнопка микрофона в поле ввода. Если Claude спросит разрешение записать файл в папку проекта, разрешите.
5. Дальше открывайте проект так же: вкладка **Code**, папка `ai-shtab`. Только в разговоре, открытом в этой папке, работают защита личных данных и правила проекта.

При знакомстве агент сам готовит рабочую папку: ставит всё для таблиц Excel, PDF и документов, около 10 минут. Решения под ваши задачи уже лежат в ней: вагоны и посадка, оплаты заводам, цены против конкурентов, план-факт продаж, коммерческие предложения и презентации.

WhatsApp агент подключает обязательно и только на вашем Mac, без серверов. База переписки хранится на этом компьютере. Агент читает только чаты, нужные для задачи, а телефоны, ИИН и почты в них заменены метками. Telegram подключается, только если понадобится. Как это устроено: [знания/мессенджеры.md](знания/мессенджеры.md).

Бонус по желанию: офис агентов, где ваши агенты работают по отделам, а решения ждут вашего «да» или «нет». Агент предложит его после знакомства, или скажите ему «поставь офис». Подробно: [бонус/офис_агентов.md](бонус/офис_агентов.md).

Что такое навыки и как с ними работать: [навыки/README.md](.claude/skills/README.md). Коннекторы (MCP) под ваши задачи и что поставить первым: [обучение/навыки_и_mcp.md](обучение/навыки_и_mcp.md). Подборка коннекторов, навыков и каналов: [бонус/полезное.md](бонус/полезное.md).

Данные вашей компании остаются на вашем компьютере. Агент ничего не покупает, не вводит пароли и пишет людям только после вашего «да».

## Для Claude и других AI-агентов

Пользователь дал тебе ссылку на этот репозиторий, а разговор открыт в другой папке. Правила проекта (`.claude/settings.json`) и сторож личных данных (`.claude/hooks/guard.py`) работают только в разговоре, открытом в папке проекта. Поэтому здесь онбординг не начинай.

1. Скачай проект в домашнюю папку пользователя:
   `git clone https://github.com/saint4ai/ai-shtab ~/ai-shtab`
   Если git не установлен или просит установить инструменты разработчика, скачай архив и распакуй:
   `curl -L -o /tmp/ai-shtab.zip https://github.com/saint4ai/ai-shtab/archive/refs/heads/main.zip && unzip -q /tmp/ai-shtab.zip -d /tmp && mv /tmp/ai-shtab-main ~/ai-shtab`
2. Попроси пользователя открыть новый разговор: Claude, вкладка **Code**, папка `ai-shtab`, написать «Привет». Там ты прочитаешь `CLAUDE.md` и начнёшь онбординг по `ОНБОРДИНГ.md`.
