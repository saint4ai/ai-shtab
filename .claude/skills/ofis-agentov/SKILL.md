# Офис агентов

Полная инструкция и правила безопасности: `бонус/офис_агентов.md`.

## Шаги

1. Проверь Node.js: `node -v`. Меньше 20 или нет совсем — объясни шаг 2 из инструкции. Ставит руководитель сам: установщик спросит пароль от Mac.
2. Спроси разрешение одной фразой: «Запустить офис агентов? Он работает только на этом компьютере, при первом запуске попросит дописать свои хуки в настройки Claude».
3. После «да» запусти в фоне строго эту версию:
   ```bash
   npx --yes pixel-agents@1.6.0 --no-terminal --port 3100
   ```
4. Найди в выводе адрес `http://127.0.0.1:3100/?token=…` и дай его руководителю. Напомни, что ссылку никому не пересылать и офис не показывать посторонним: над человечками видны названия задач.
5. Человечков нет — попроси открыть в офисе Settings → Watch All Sessions. Всё равно пусто — запиши в `обучение/вопросы_к_созвону.md`: «офис агентов не видит сессии Claude Desktop».

## Нельзя

- Ставить другую версию, включать `--host 0.0.0.0`, Tailscale и «Usage Bars».
- Менять `.claude/settings.json` проекта ради офиса: свои хуки офис ставит сам, с согласия руководителя.
