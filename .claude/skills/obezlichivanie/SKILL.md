# Обезличивание

Скрипт `tools/obezlichit.py` работает только на этом компьютере и в интернет ничего не отправляет.

## Обезличить

```bash
python3 tools/obezlichit.py mask "входящие/клиенты.xlsx" --columns "Клиент,Контрагент,ФИО"
```

- По всему файлу заменяет ИИН и БИН, телефоны и почты на метки вида `ИИН-001`, `Телефон-001`.
- Значения в колонках из `--columns` заменяет на метки по названию колонки: `Клиент-001`.
- Пишет копию рядом с исходником: `клиенты.обезл.xlsx`. Дальше работай только с копией, исходник не открывай.
- Таблица соответствий лежит в `.private/`. Её не открывай.
- Поддерживаются `.xlsx`, `.csv`, `.txt`, `.md`. Для `.xlsx` нужен openpyxl: если скрипт попросит, установи `python3 -m pip install --user openpyxl` после «да» руководителя.

## Вернуть настоящие имена в готовый отчёт

```bash
python3 tools/obezlichit.py restore "сводки/2026-11-20.md"
```

Скрипт пишет копию с настоящими именами в `.private/восстановлено/` и печатает только путь. Содержимое не читай: скажи руководителю, где лежит файл.
