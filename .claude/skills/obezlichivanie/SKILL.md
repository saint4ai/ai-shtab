# Обезличивание

Скрипт `tools/obezlichit.py` работает только на этом компьютере и в интернет ничего не отправляет.

## Шлюз входящих: всегда первым

```bash
python3 tools/obezlichit.py inbox
```

- Проверяет каждый новый файл во `входящие/`. Нашёл персональные данные — пишет копию `имя.обезл.ext`, а исходник убирает в `.private/исходники/`.
- Файлы без персональных данных оставляет как есть.
- Печатает только сводку, содержимое не печатает.
- Колонки с названиями клиентов (Клиент, Покупатель, Контрагент, Заказчик, ФИО) получают метку `Клиент-001` во всех таблицах. Одинаковый клиент в разных таблицах получает одну и ту же метку, поэтому таблицы можно сопоставлять.
- В свободном тексте (расшифровки, заметки) скрипт находит только ИИН, телефоны и почты. Названия клиентов в тексте он не видит.

Пока шлюз не отработал, сторож проекта (`.claude/hooks/guard.py`) не даст открыть файлы входящих. Папка `.private/` закрыта всегда.

## Если колонка называется необычно

```bash
python3 tools/obezlichit.py mask "входящие/файл.xlsx" --columns "Наименование" --kind Клиент
```

## Вернуть настоящие названия в готовый отчёт

```bash
python3 tools/obezlichit.py restore "презентации/2026-11-20_продажи.html"
```

Копия с настоящими названиями ложится в `.private/восстановлено/`. Агенту она закрыта: скажи руководителю, где лежит файл.

## Нужно для работы

python3 (есть на Mac с инструментами разработчика). Для `.xlsx` нужен openpyxl: `python3 -m pip install --user openpyxl`, ставить после «да» руководителя.
