# Личный день

Работает, только если руководитель включил личное на онбординге: есть файл `личное/цели.md`.

## Вход

- `личное/цели.md`: цели «я, семья, дело», план тренировок, питание, семейные даты.
- Встречи: календарь, который руководитель прислал или продиктовал. Календарь Mac читай только после его «да»: macOS сама спросит разрешение.
- Задачи дня из утренней сводки и `знания/приоритеты.md`.

## План дня

| Время | Я | Семья | Дело |

- Сначала то, что не двигается: тренировка, семья, встречи.
- В «Дело» не больше трёх задач. Первой ставь ту, что приносит деньги.
- Операционные задачи, которые можно поручить, вынеси отдельным списком «поручить» с именами.

## Неделя

По понедельникам: план недели по трём сферам и семейные даты на две недели вперёд.

Данные о здоровье и семье остаются в `личное/` и никуда не отправляются.
