# PDF-презентация из HTML

## Как собирать

1. Сделай HTML по навыку `html-prezentaciya`, оформление по `frontend-design`. Для PDF лист фиксированного размера, а не экран:
   ```css
   @page { size: 297mm 210mm; margin: 0; }
   section {
     width: 297mm; height: 210mm; padding: 14mm 18mm;
     box-sizing: border-box; overflow: hidden;
     display: flex; flex-direction: column; justify-content: center;
     break-after: page;
   }
   section:last-of-type { break-after: auto; }
   ```
   По умолчанию альбомный A4. Книжный (`210mm 297mm`) только если просят «для печати».
2. Собери PDF:
   ```bash
   python3 tools/sobrat_pdf.py презентации/тема.html
   python3 tools/sobrat_pdf.py презентации/тема.html --knizhnaya
   ```
   Скрипт рендерит страницу настоящим Chromium, ждёт шрифты, кладёт PDF рядом с HTML и убирает пустые листы.
3. Открой PDF командой `open` и проверь глазами (список ниже). Потом покажи руководителю.

## Что проверить в PDF

- Сколько листов, столько и слайдов, пустых нет.
- Шрифт применился, Times New Roman вместо него не подставился.
- Картинки на месте, текст не обрезан по краю листа.
- Ссылки кликаются.
- Имя файла понятное: `План-факт_ноябрь.pdf`, а не `output.pdf`.

## Частые ошибки

| Симптом | Причина | Что сделать |
|---|---|---|
| Пустой лист в конце | лишний блок после последней `<section>` | скрипт уберёт сам; лучше убрать блок из HTML |
| Текст уехал за край | нет `box-sizing: border-box` | добавить в `section` |
| Шрифт стал Times | шрифт не успел загрузиться или нет интернета | скрипт ждёт 2 с; без интернета задать запасной системный шрифт |
| PDF больше 10 МБ | огромные фото | уменьшить фото до 2000 px по длинной стороне перед вставкой |
| На телефоне белые листы | фон из больших градиентов | заменить градиенты на однотонный фон или картинку |

## Правила

- Анимации и наведения в PDF не нужны: PDF статичен.
- Картинки лежат рядом с HTML, а не по ссылкам из интернета.
- Цифры только сверенные (`sverka`). Отправка людям только после «да» руководителя.
- Установка инструментов: раздел «Первая установка» в навыке `html-prezentaciya`.
