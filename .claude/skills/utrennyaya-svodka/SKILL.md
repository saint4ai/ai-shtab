# Утренняя сводка

## Источники

Бери самые свежие файлы и называй их дату.

- Продажи: план-факт во `входящие/` (расчёт как в навыке `plan-fakt-prodazh`).
- Вагоны: таблица отгрузок (правила навыка `kontrol-vagonov`).
- Поручения: задачи из `протоколы/` со сроком сегодня, завтра или просроченные; выгрузка задач Битрикс24, если есть.
- Производство: выгрузка 1С (навык `plan-fakt-proizvodstva`).
- День: `личное/`, только если руководитель включил личное на онбординге.
- Прислали за ночь: `python3 tools/whatsapp.py files --hours 12`, затем `python3 tools/obezlichit.py inbox` (навык `whatsapp`, раздел «Присланные файлы»). Каждый файл открой и разбери: что это и что в нём главное.

## Формат

Время и вид из `знания/предпочтения.md`. По умолчанию:

```
Доброе утро, <обращение>. Главное на <дата>:
Продажи: …
Вагоны: …
Поручения: …
Производство: …
Прислали за ночь: <кто> — <что за файл> — <главное> → <что делать>
Ваш день: …
Фокус дня: …
Требует решения: …
Источники: <файл (дата)>, …
```

- Не больше девяти строк, плюс по строке на каждый присланный файл, до пяти. Цифры, без пересказа.
- «Прислали за ночь»: имя отправителя как в WhatsApp, тип файла (прайс, таблица, счёт, фото документа), главное в одной фразе и действие («сравнить с нашими ценами», «проверить вагоны», «передать бухгалтеру»). Файлов больше пяти — пять главных и «ещё N».
- «Фокус дня»: одно-два дела, которые сегодня приносят деньги, по `знания/приоритеты.md`. Операционное, что можно поручить, сюда не ставь.
- Раздела нет в данных — «нет данных за <дата>». Ничего не досчитывать из головы.
- «Требует решения» только если есть что решать, максимум два пункта.

## Порядок

1. Собери цифры по разделам.
2. Отдай черновик агенту `sverka` вместе со списком файлов.
3. Исправь расхождения и покажи руководителю.
4. Сохрани в `сводки/ГГГГ-ММ-ДД.md`.
5. Если из сводки следует «напомнить кому-то», предложи черновик сообщения и жди «да».
6. Подключены номер агента и группа (навык `whatsapp`, раздел «Номер агента») — отправь сводку туда: `python3 tools/whatsapp.py post - <<'EOF'`. Картинкой: сверстай сводку в `сводки/ГГГГ-ММ-ДД.html`, `python3 tools/kartinka.py сводки/ГГГГ-ММ-ДД.html сводки/ГГГГ-ММ-ДД.png`, затем `post --file сводки/ГГГГ-ММ-ДД.png "Сводка на <дата>"`.
