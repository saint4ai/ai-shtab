# HTML-презентация, которая открывается в WhatsApp

## Почему так

WhatsApp на iPhone показывает HTML-файл во встроенном просмотрщике, а **скрипты там не работают**. Всё, что рисует JavaScript, остаётся пустым: перелистывание слайдов стрелками, графики на скриптах, анимированные окна, видео. Поэтому:

- слайды идут **сверху вниз**, их листают пальцем. Каждый слайд — это `<section>`;
- графики рисуем **встроенным SVG** прямо в HTML;
- всё, что двигается, перед отправкой превращаем в **GIF**, его телефон проигрывает сам.

## Как делать

1. Оформление по навыку `frontend-design`: выразительный шрифт с Google Fonts и запасной системный, одна акцентная краска, крупные цифры, воздух. Бренд компании, если он есть, важнее советов навыка.
2. Один файл `презентации/ГГГГ-ММ-ДД_тема.html`. Стили внутри файла, картинки рядом с ним, ссылок на чужие сайты нет.
3. Каждый слайд — `<section>` высотой не меньше экрана (`min-height:100vh`), на телефоне шириной 390 px ничего не уезжает вбок.
4. Если нужна анимация, например окно с ходом работы, это отдельная сцена в `<iframe srcdoc="..." style="width:640px;height:740px">` фиксированного размера. На компьютере она играет вживую.
5. Перед отправкой в мессенджер собери версию без скриптов:
   ```bash
   python3 tools/html_v_whatsapp.py презентации/тема.html презентации/тема_whatsapp.html
   ```
   Скрипт записывает каждую сцену и видео в GIF, встраивает картинки внутрь файла и удаляет скрипты. Хорошо, если файл весит до 10 МБ.
6. Покажи руководителю обе версии командой `open`. Перед отправкой людям руководитель отправляет файл себе в WhatsApp и смотрит на телефоне.

## Первая установка

Один раз, только после «да» руководителя:
```bash
python3 -m pip install --user playwright pypdf imageio-ffmpeg
python3 -m playwright install chromium
```
Если на компьютере есть Google Chrome, вторая команда не обязательна: скрипты возьмут его.

## Правила

- Один слайд — одна мысль. У каждой цифры источник мелким шрифтом внизу слайда.
- Цифры только из таблиц, сверенных агентом `sverka`. Ничего не придумывать.
- Имена клиентов и телефоны в презентации для посторонних только с разрешения руководителя.
- Отправить файл людям можно только после «да» руководителя (правило 2 в AGENTS.md).
- Нужен PDF для печати или почты: навык `pdf-prezentaciya`.
