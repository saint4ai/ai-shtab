# Клиенты конкурентов

## Вход

- Продажи конкурентов за период из `входящие/`: конкурент, покупатель, город, товар, объём, цена. Сведи к `шаблоны/продажи_конкурентов.csv`.
- Наша клиентская база с датой последней отгрузки.

Сначала шлюз `python3 tools/obezlichit.py inbox` (навык `obezlichivanie`). Колонки с клиентами в обеих таблицах получат метки `Клиент-NNN`, одинаковый клиент — одну и ту же метку, поэтому таблицы сопоставляются по меткам. Если колонка с клиентами названа необычно, обезличь её командой `mask … --kind Клиент`.

## Разбор

1. Новые: покупают у конкурентов, у нас не покупали. Сортируй по объёму.
2. Общие: наши клиенты, которые берут и у конкурента. По каким товарам и по какой цене.
3. Ушли к конкуренту: у нас нет отгрузок дольше порога из `знания/регламенты.md`, а у конкурента покупают. Их возвращаем первыми.
4. Цену конкурента в каждой сделке сравни с нашим прайсом по тому же товару и городу.

## Результат

Три таблицы: новые, общие, ушедшие. Показывай все три, даже если какая-то пустая (тогда «нет»). В каждой объём и цена конкурента. Под ними черновики задач менеджерам по филиалам.

Задачи и сообщения только после «да». Настоящие названия клиентов возвращай в готовый отчёт командой `restore` навыка `obezlichivanie`.
