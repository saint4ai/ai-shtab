# Офис агентов (бонус, по желанию)

[Pixel Agents](https://github.com/pixel-agents-hq/pixel-agents) показывает ваших агентов Claude человечками в пиксельном офисе. Польза не в картинке. Сразу видно, какой агент работает, какой закончил, а какой встал и ждёт вашего ответа. Когда открыто несколько задач, последнее легко пропустить.

Проект открытый: около 10 тысяч звёзд на GitHub, лицензия MIT, версия 1.6.0 от 10.11.2026.

## Безопасность

- Офис работает только на этом компьютере: открывается по адресу `127.0.0.1`, вход по ключу из ссылки. В исходниках нет отправки данных наружу.
- Ставим строго версию 1.6.0. Обновляем только вместе с Александром.
- Над человечками видны названия задач, они берутся из ваших запросов. Не показывайте офис на экране посторонним.
- Не включать доступ из сети (`--host 0.0.0.0`, Tailscale) и «Usage Bars».
- Ссылку с ключом никому не пересылайте.

## Установка, 5 минут

1. Откройте Терминал (Cmd + Пробел, «Терминал», Enter) и вставьте `node -v`. Если число 20 или больше, переходите к шагу 3.
2. Скачайте установщик Node.js LTS с https://nodejs.org (файл .pkg) и установите. Mac спросит пароль от компьютера, это нормально. Закройте и снова откройте Терминал.
3. Вставьте и нажмите Enter:
   ```bash
   npx pixel-agents@1.6.0 --no-terminal --port 3100
   ```
   На вопрос «Ok to proceed?» ответьте `y`. Терминал покажет адрес вида `http://127.0.0.1:3100/?token=…`. Окно Терминала не закрывайте, пока пользуетесь офисом.
4. Откройте этот адрес в браузере. При первом запуске офис попросит разрешение дописать свои хуки в настройки Claude. Подтвердите.
5. В Claude Desktop откройте вкладку Code, папку `ai-shtab` и дайте любую задачу. За столом появится человечек. Если пусто, в офисе откройте Settings → Watch All Sessions.

## Если человечков нет

Значит, вкладка Code в Claude Desktop не передаёт события офису. Скажите на созвоне: подключим запасной вариант [Claude Code Agent Monitor](https://github.com/hoangsonww/Claude-Code-Agent-Monitor) с деревом агентов и историей, но без человечков.

## Выключить и удалить

- Выключить: Ctrl + C в окне Терминала.
- Удалить: в файле `~/.claude/settings.json` убрать записи, где есть `pixel-agents`, и удалить папку `~/.pixel-agents`.

## Чего офис не умеет

Очередей задач и канбана нет. Агенты, запущенные изнутри навыков, иногда не показываются. Это наглядная панель внимания, а не учёт работы.
